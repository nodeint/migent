# @nodeint/migent-adapters

Provider adapters for Migent.

See [Adapter architecture and contracts](../../docs/adpaters.md) for client binding,
headless discovery, execution, validation, failure handling, and usage accounting.

This package is an internal dependency of the Migent CLI and has no stable public API.

For installation, usage, and documentation, see [the Migent CLI on npm](https://www.npmjs.com/package/@nodeint/migent).
